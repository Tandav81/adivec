ÉTAPES
------
1. Par sécurité, télécharger depuis le serveur public/.htaccess (il va être écrasé).
2. Téléverser public/.htaccess et public/410.html dans public/ sur le serveur.
3. Vérifier dans le navigateur :
   - https://www.adivec.fr/Rub_79/Fr/L-alimentaire/Gelifiants-Epaississants/E-425-Konjac.html
     → fiche Konjac ;
   - https://www.adivec.fr/Rub_54/Fr/Menu-haut/L-alimentaire/Amidons/Amidon-d-Arrow-Root.html
     → page « Cette page n'existe plus » (F12 > Réseau : statut 410) ;
   - https://www.adivec.fr/Rub_42/Fr/Actualites.html → /news ;
   - https://www.adivec.fr/?IdRubrique=30 → accueil ;
   - l'accueil, une fiche produit, /contact et une image s'affichent normalement.
   En cas d'erreur 500 sur tout le site : remettre le .htaccess sauvegardé (une erreur de
   syntaxe dans ce fichier bloque tout le site).
4. Search Console : les URL en 410 vont passer du rapport « Page avec redirection » à
   « Introuvable (404) » (Google range les 410 dans cette catégorie). C'est voulu : ne pas
   cliquer sur « Valider la correction » pour celles-là. Elles disparaîtront d'elles-mêmes.
