ÉTAPES
------
1. Sauvegarder la base de prod (phpMyAdmin > Exporter) et, par sécurité, les dossiers
   src/, templates/, config/ et public/.htaccess du serveur.
2. Base de données EN PREMIER (l'ancien code fonctionne avec la nouvelle base, l'inverse non :
   téléverser le code avant provoquerait des erreurs 500 le temps de la migration).
   Exécuter « 2026-10-01-migrations-prod.sql » dans phpMyAdmin (onglet SQL).
   (Alternative si la console Symfony est disponible sur le serveur : téléverser d'abord
   le seul dossier migrations/, lancer  php bin/console doctrine:migrations:migrate,
   puis passer à l'étape 3. Ne pas faire les deux.)
3. Téléverser TOUT le contenu de « 2026-10-01-a-televerser/ » à la racine du site
   (là où se trouvent src/, templates/, public/…) en écrasant les fichiers existants.
   → 334 fichiers, ~23 Mo.
4. Vider le cache : php bin/console cache:clear --env=prod
   (ou supprimer le dossier var/cache/prod/ par FTP).
5. Vérifier :
   - https://www.adivec.fr/product/gomme-de-guar-1  → doit rediriger vers /product/gomme-de-guar
   - https://www.adivec.fr/sitemap.xml               → 168 URL
   - une image : dans Chrome, outils dev > Réseau > img/flour-bowl.png → Type « webp »
6. Search Console : renvoyer le sitemap.
